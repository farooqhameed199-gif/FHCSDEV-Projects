# FHCSDEV-Projects
A curated collection of Python, Web Stack, and C++ assignments and tutorials developed for the FH CSDev learning ecosystem.

Tech Stack
Python: Interactive CLI tools, logic building, and foundational concepts.

Web Stack: HTML5, CSS3, and JavaScript (focusing on modern UI layouts and DOM manipulation).

C++: Algorithmic challenges and core computer science fundamentals.

Node.js: Backend environment execution scripts.
